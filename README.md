# torba.travel

Статический сайт мастерской «Торба» (Томск). Одна страница, без сборки и без бэкенда:
`index.html` + `assets/` открываются напрямую в браузере.

## Что внутри

| Файл / папка | Назначение |
|---|---|
| `index.html` | Вся страница: разметка, стили, JS-компоненты |
| `assets/` | Фото, шрифты (woff2), React 18 и рантайм компонентов — всё локально, внешних CDN нет |
| `404.html` | Копия главной: любой несуществующий адрес показывает сайт, а не ошибку GitHub |
| `CNAME` | Домен для GitHub Pages — `torba.travel` |
| `.nojekyll` | Отключает Jekyll, иначе Pages игнорирует служебные файлы |
| `favicon.svg`, `og-image.jpg` | Иконка вкладки и превью для Telegram / VK / WhatsApp |
| `robots.txt`, `sitemap.xml` | Для Яндекса и Google |
| `.github/workflows/deploy.yml` | Автодеплой: каждый push в `main` публикует сайт |

## Публикация (по шагам)

### 1. Репозиторий на GitHub

Создать **публичный** репозиторий, например `torba-travel`, без README и .gitignore
(они уже здесь). Затем из этой папки:

```bash
git remote add origin https://github.com/<логин>/torba-travel.git
git push -u origin main
```

> Приватный репозиторий тоже возможен, но GitHub Pages на нём работает только
> на платном тарифе Pro. Для публичного — бесплатно.

### 2. Включить Pages

`Settings` → `Pages` → **Source: GitHub Actions**.

Первый деплой запустится сам после push, идёт ~1 минуту. Прогресс — во вкладке
`Actions`. Проверить результат до подключения домена можно по адресу
`https://<логин>.github.io/torba-travel/`.

> На этом адресе часть картинок может не отображаться: сайт лежит в подпапке, а
> ссылки абсолютные. На своём домене всё встанет на место — это не ошибка сборки.

### 3. DNS у регистратора

Для `torba.travel` (корневой домен) — четыре A-записи:

```
@   A   185.199.108.153
@   A   185.199.109.153
@   A   185.199.110.153
@   A   185.199.111.153
```

И одна запись для `www`:

```
www CNAME  <логин>.github.io.
```

TTL — минимальный из доступных (300–600 с), потом можно вернуть обычный.

### 4. Домен в GitHub

`Settings` → `Pages` → `Custom domain` → `torba.travel` → `Save`.
Дождаться зелёной галочки «DNS check successful» (от 10 минут до нескольких
часов), затем включить **Enforce HTTPS** — сертификат Let's Encrypt выпускается
автоматически.

### 5. Проверка

```bash
dig +short torba.travel            # должны быть четыре адреса 185.199.10x.153
curl -sI https://torba.travel | head -1   # HTTP/2 200
```

## Обновление сайта

Любое изменение файлов → `git commit` → `git push`. Через минуту оно на домене.
Если правки не видны — жёсткое обновление страницы (Cmd+Shift+R): GitHub Pages
кэширует `index.html` до 10 минут.

## Что стоит сделать дальше

- **Вес страницы.** ~4,3 МБ, из них 1,4 МБ — один PNG (`torba-kemperboks-v-bagazhnike.png`).
  Перевод фото в WebP и `loading="lazy"` уберут около половины веса.
- **Аналитика.** Яндекс.Метрика — одна вставка в `<head>`.
- **Формы.** Сейчас заявки идут только через телефон, почту и Telegram. Если
  появится форма на сайте — это персональные данные (152-ФЗ): понадобятся
  политика обработки, чекбокс согласия и сервер приёма заявок в РФ.
  GitHub Pages статичен и формы принимать не умеет.
- **Индексация.** После запуска — добавить сайт в Яндекс.Вебмастер и Google
  Search Console, там же скормить `sitemap.xml`.
